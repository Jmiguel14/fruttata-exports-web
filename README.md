# Fruttata Exports Web

Informative corporate website for Fruttata Exports S.A.S., built with Next.js, TypeScript, Tailwind CSS, and next-intl. Bilingual (ES/EN) with a contact form delivered through Resend.

## Stack

- Next.js (App Router, Cache Components)
- TypeScript
- Tailwind CSS
- next-intl (localized routes and messages)
- Zod (form validation) and Resend (email delivery)
- lucide-react and country-flag-icons (icons and flags)
- Deploy target: Vercel

## Routes

Internal folders stay in English. Public URLs are localized.

| Internal path | Spanish | English |
| --- | --- | --- |
| `/` | `/es` | `/en` |
| `/products` | `/es/productos` | `/en/products` |
| `/about` | `/es/nosotros` | `/en/about` |
| `/contact` | `/es/contacto` | `/en/contact` |

`/` redirects to `/es`. Unknown URLs render a localized 404. `sitemap.xml` and `robots.txt` are generated by the app.

## Environment variables

Copy `.env.example` to `.env.local` for local work. On Vercel, add the same variables in Project Settings > Environment Variables.

| Variable | Purpose |
| --- | --- |
| `CONTACT_FORM_ENABLED` | `true` shows the contact form. Anything else shows WhatsApp buttons and contact details. |
| `RESEND_API_KEY` | Resend API key (required when the form is enabled). |
| `RESEND_FROM_EMAIL` | Sender on a domain verified in Resend (SPF/DKIM). |
| `CONTACT_TO_EMAIL` | Inquiry recipients (comma-separated). |
| `CONTACT_CC_EMAIL` | Optional CC recipients. |
| `NEXT_PUBLIC_SITE_URL` | Public site URL for canonical links, hreflang, sitemap, and Open Graph. |

The contact pages are prerendered, so `CONTACT_FORM_ENABLED` is read at build time. Changing it on Vercel requires a redeploy.

## Contact form

- Server Action with Zod validation; the flag is re-checked on the server.
- Spam protection: honeypot field and a minimum fill time. There is no rate limiting.
- `/contact?product=<id>` preselects a fruit (used by the "Request a quote" button on product cards).
- Emails are always written in Spanish and include the visitor's language.
